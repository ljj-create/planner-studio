# Planner Studio

个人使用的计划与每日日程管理桌面软件。以透明挂件形式嵌入桌面显示（不覆盖其他窗口），打开即看，简洁易用，数据完全本地存储。

## 功能

- **桌面挂件**：透明毛玻璃小窗，挂载在桌面层级（其他软件打开时不会遮挡桌面外的界面，挂件始终贴着桌面显示）
- **激励语**：挂件顶部自定义一句话，双击编辑，随主题自适应
- **未来任务倒计时**：实时显示剩余天数/小时/分钟，过期标红，到期弹系统通知
- **每日待办**：勾选完成、删除、双击编辑，实时进度条
- **优先级**：高/中/低，自动排序，色条区分
- **重复任务**：每天 / 工作日 / 每周一自动生成；某天不想做可直接删除当天任务，当天不再出现，后续每天照常生成（模板独立保存，删除任意一天的实例都不影响）；**管理窗口点击任务旁的"每日/每周一"标签可修改周期（改每天/工作日/每周一/不重复）或永久删除整个重复任务**
- **统计面板**：本周 / 本月两套视图，完成率环比上周同期、上月同期，周柱状图、月度热力图（点格子跳到日历对应日期），以及按日期倒序列出的**已完成任务名**（同一天同名的重复任务合并成 ×N），连续完成天数
- **日历视图**：紧凑月历查看待办与任务分布，点选日期查看/操作
- **主题切换**：浅色 / 深色，两窗口同步
- **数据备份**：一键导出 / 导入 JSON，防数据丢失
- **托盘**：托盘图标右键可显示/隐藏挂件或退出，开机自启（自启动时挂件自动定位屏幕右上角），任务到期提醒开关

## 安装

下载并运行 `dist/` 目录下的 `Planner Studio Setup x.y.z.exe`，按向导安装即可。

## 使用说明

- **挂件**：顶部激励语（双击编辑、按住可拖动位置）；中间今日待办（**只可勾选完成，无删除按钮防误删**）；下方倒计时列表；**在挂件任意位置右键打开管理窗口**
- **管理窗口**（挂件右键打开）：
  - 未来任务：添加（名称 + 截止时间）、删除、清除已过期
  - 今日待办：添加（可选优先级和重复规则）、勾选、删除、双击编辑
  - 统计：本周 / 本月切换，完成率与环比、每日图表、已完成任务清单
  - 设置：主题、提醒开关、开机自启、数据备份
  - 日历：紧凑布局，左侧月历右侧选中日期安排（切换月份、点击日期查看/操作）
- **统计口径**：周按自然周（周一至周日）、月按自然月；汇总只统计到今天，未来日期在图表里留空。环比对比的是上一周期的**同期**区间（如本周一到今天 vs 上周一到上周同一天），避免拿半周去比整周
- **退出**：托盘图标右键 → 退出（挂件没有关闭按钮，防止误关）
- **单实例**：重复启动会激活已在运行的实例（挂件显示并打开管理窗口），不会起第二个进程去抢同一个数据文件

数据保存在 `%APPDATA%/planner-studio/data.json`（未打包运行时为 Electron 用户数据目录）。

## 数据与备份

结构带 `version` 字段（当前为 1），加载时会按版本迁移：

- `futureTasks`：未来任务（倒计时）
- `todos`：按 `YYYY-MM-DD` 分桶的每日待办
- `repeatTemplates`：重复任务模板（删掉某天实例不影响模板）
- `repeatSkips`：重复任务被手动删除的日期，当天不再生成
- `settings`：主题、提醒开关、开机自启、激励语
- `version`：数据结构版本

写入采用「先写 `data.json.tmp` 再原子替换」，避免写到一半崩溃留下半截文件。若文件已损坏无法解析，会改名为 `data.json.corrupt-<时间戳>` 留档，应用以空数据启动，不会把原文件直接覆盖掉。

导出 / 导入在管理窗口 → 设置 → 数据备份。导入会替换任务与待办（含重复任务模板和跳过记录），但**保留当前设置**，不会因一份旧备份把主题和提醒开关改回去。

## 开发

技术栈：Electron + 原生 HTML/CSS/JS，无前端框架，数据 JSON 本地存储。

```
planner-studio/
├─ main.js               # 主进程：双窗口、IPC、通知、托盘、备份、桌面挂载
├─ preload.js            # contextBridge 白名单 API
├─ data-store.js         # 数据模块：CRUD、重复任务、跳过机制、统计、持久化
├─ renderer/
│  ├─ widget.*           # 桌面挂件（展示 + 待办操作 + 激励语 + 右键管理）
│  ├─ manager.*          # 管理窗口（添加/编辑/统计/设置/日历）
├─ test/                 # data-store 的 node:test 单测
├─ scripts/              # 工程脚本（提交信息校验）
├─ docs/                 # 架构审查报告与工程规范
├─ .githooks/            # 提交前单测、提交信息格式校验
├─ .github/workflows/    # GitHub Actions CI
├─ build/icon.png        # 打包图标
├─ assets/tray.png       # 托盘图标
├─ assets/attach-desktop.ps1  # 挂载挂件到桌面层级（WorkerW）
```

### 命令

```bash
npm install        # 安装依赖（国内网络建议: npm config set registry https://registry.npmmirror.com）
npm start          # 启动应用
npm test           # 运行数据模块单测
npm run lint       # ESLint 检查
npm run verify     # 单测 + ESLint，提交前跑这个
npm run hooks:install  # 启用提交钩子（首次克隆后执行一次）
npm run pack       # 打包 Windows 安装包（生成于 dist/）
```
